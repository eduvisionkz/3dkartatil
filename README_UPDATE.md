# 2026-10-01 жаңарту

Қазіргі GitHub main файлдары негізге алынды. Автор/жетекші мәліметтері, тарихи кезеңдер, шекара режимдері, оқиғалар мен тест сақталған.

Қосылды: алты өңірдің күнделікті мемлекеттік тіл қолдану үлесі; санақтағы бастапқы сандар; карта карточкасындағы екі тілдік көрсеткіш; салыстыру және нәтиже беттеріндегі кесте; екі өңір айырмасын есептеу. Қарағанды дерегінің Ұлытау аумағымен бірге есептелгені көрсетілді.

Дереккөз: Ұлттық статистика бюросы, «Қысқаша қорытындылар», 2021 жылғы санақ, 5.2-кесте. Есептік топ — 5 жас және одан үлкен халық.

GitHub арқылы жаңарту: eduvisionkz/3dkartatil репозиторийінің main тармағына архивтегі сайт файлдарын салыңыз. README_UPDATE.md қызметтік түсіндірме. GitHub Pages жарияланған соң compare.html, results.html және map.html беттерін тексеріңіз.
